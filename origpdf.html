Installation et vérification

Windows

L'installateur n'est pas encore signé par un certificat éditeur : si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires », puis « Exécuter quand même ».

macOS

  1. Ouvrez le fichier .dmg et glissez OrigPDF dans Applications.
  2. OrigPDF n'est pas encore notarisé par Apple. À la première ouverture, macOS le bloque : ouvrez Réglages Système › Confidentialité et sécurité, puis cliquez sur « Ouvrir quand même ». Sur macOS 14 et antérieur, un clic droit sur l'app › Ouvrir suffit.
  3. Si macOS indique que l'app « est endommagée », lancez dans le Terminal : xattr -dr com.apple.quarantine /Applications/OrigPDF.app

Empreintes SHA-256

Windows

The installer is not yet signed with a publisher certificate: if Windows shows “Windows protected your PC”, click “More info”, then “Run anyway”.

macOS

  1. Open the .dmg file and drag OrigPDF into Applications.
  2. OrigPDF is not yet notarized by Apple. The first time you open it, macOS blocks it: go to System Settings › Privacy & Security and click “Open Anyway”. On macOS 14 and earlier, right-click the app › Open is enough.
  3. If macOS says the app “is damaged”, run this in Terminal: xattr -dr com.apple.quarantine /Applications/OrigPDF.app
