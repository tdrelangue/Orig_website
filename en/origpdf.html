Installation and verification

Windows

The installer is not yet signed with a publisher certificate: if Windows shows “Windows protected your PC”, click “More info”, then “Run anyway”.

macOS

  1. Open the .dmg file and drag OrigPDF into Applications.
  2. OrigPDF is not yet notarized by Apple. The first time you open it, macOS blocks it: go to System Settings › Privacy & Security and click “Open Anyway”. On macOS 14 and earlier, right-click the app › Open is enough.
  3. If macOS says the app “is damaged”, run this in Terminal: xattr -dr com.apple.quarantine /Applications/OrigPDF.app
